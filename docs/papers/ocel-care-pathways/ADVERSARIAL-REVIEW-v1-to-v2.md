# Adversarial self-review of v1.0 → dispositions implemented in v2.0

**Paper:** An Object-Centric Event Log Architecture for Governed Modeling and Measurement of Inpatient Care Pathways
**Review date:** 2026-07-24 · Reviewer stance: hostile methodologist + clinical measurement expert + biostatistician + implementation scientist
**Outcome:** 16 findings (5 major, 6 moderate, 5 minor). All 16 implemented in v2.0.

| # | Severity | Finding | Disposition in v2.0 |
|---|---|---|---|
| R1 | MAJOR | Terminology collision: "deficiency" used in two incompatible senses — the OCPM flattening metric (van der Aalst) and the care-measurement sense (missed care). A reviewer would call this fatal ambiguity in the paper's own vocabulary. | Flattening metric renamed **event loss** ("deficiency" retained once, parenthetically, as the OCPM literature term). Care-sense "deficiency" now unique to the measurement framework. Abstract, Methods, Results, Table 4 caption, Figure 6 caption updated. |
| R2 | MAJOR | Single-snapshot fragility: all percentages measured once against a store that refreshes every 15 minutes; no evidence the proportions are stable rather than artifacts of one draw. | New **snapshot-stability analysis**: morning values derived from the specification's independently published per-class rates (24.3% patient / 82.1% encounter on 19,322 events) vs. evening measured census (24.1% / 81.9% on 19,439); full query re-execution later the same evening reproduced evening values exactly. Reported in Results. |
| R3 | MAJOR | Under-specified experiment: flattening metrics defined informally; one-hop O2O closure direction and counting semantics unstated; a referee could not re-implement from the text. | Formal notation added to Methods: E, R_T(e), retained set E_T, L_T = {(e,o)}, event loss = 1−|E_T|/|E|, duplication factor |L_T|/|E_T|; closure R′_T defined direction-agnostic over one O2O hop; distinct-count semantics stated. |
| R4 | MAJOR | Reproducibility gap: "queries available on request" is below current standards for a data-audit paper. | **Supplementary Appendix added to both documents** containing the complete audit SQL (census; connectivity; event loss; one-hop closure + duplication distribution; identity/granularity overlap). Data-availability statement updated. |
| R5 | MAJOR | Engineered-result objection: a skeptic can claim the synthetic generator was tuned to produce dramatic flattening loss. | Methods now state provenance: generator and projector predate this analysis and were built for command-center realism, not flattening demonstrations. Discussion Q3 adds a concrete external **replication protocol** (apply the appendix queries to a MIMIC-IV-derived OCEL per Park et al.) making every Table 4 metric recomputable on real data. |
| R6 | MODERATE | Unauditable novelty claim ("to our knowledge"). | Claim scoped to the verification method: PubMed/arXiv/DBLP sweep (2022–2026) conducted during citation verification; the two known healthcare-OCPM precedents are cited. |
| R7 | MODERATE | Identity-fragmentation overreach: 0-of-602 overlap framed as defect; the two namespaces differ by *granularity* (unit-level vs bed-level location coding), which could be intended design. | Reframed as **granularity mismatch without a governed crosswalk**: the mismatch itself is not an error; the measured gap is identity_links = 0 (no crosswalk), which leaves the recovery join unanswerable. Verified counts added: 24 barrier-linked unit-level IDs vs 432 bed-granular IDs. Abstract, Results, Discussion, Figure 6 caption updated. |
| R8 | MODERATE | Duplication opacity: "354 events into 2–4 cases" hides the distribution. | Exact multiplicity distribution added: 264 events ×2, 86 ×3, 4 ×4; row checksum shown (15,575 + 528 + 258 + 16 = 16,377). |
| R9 | MODERATE | No internal-consistency evidence for the census arithmetic. | Arithmetic identities now stated in Results: nine source classes sum to 19,439; eight lost classes sum to 3,510; 56,026/19,439 reproduces the 2.88 mean. |
| R10 | MODERATE | Clinical effect sizes vague ("associated with higher mortality"). | Exact estimates with CIs added for Seymour 2017 (bundle OR 1.04/h, 1.02–1.05; antibiotics OR 1.04/h, 1.03–1.06) **including the discordant fluid-bolus null** (OR 1.01/h, 0.99–1.02) — evidence reported against, not only for, timing salience. |
| R11 | MODERATE | No reporting-guideline anchor. | Reporting aligned to **STARE-HI** where its items apply to a design-science evaluation; cited (new ref 73). |
| R12 | MINOR | Precision nits: "≈187 tests"; "100% qualifier coverage" ambiguous (schema-forced vs measured); 10,588 vs 10,589 crosswalk rows; collision bound at one n only. | Exact 187 (129 PHP + 35 Python + 23 TS); qualifier coverage flagged as *measured* (column is nullable); worksheet-header note added; collision bound generalized (n²/2⁴⁹: 0.18% at 10⁶, ≈16% at 10⁷). |
| R13 | MINOR | Multi-perspective alternatives under-cited (looks like OCEL advocacy). | Event knowledge graphs and OpenSLEX meta-model positioned as alternatives; OCEL chosen for standardized interchange + tooling; governance layer independent of that choice (new ref 74). |
| R14 | MINOR | Feasibility argument (Q7) lacked scale arithmetic. | Fixture bound added: 60–120 per pathway → 15,000–30,000 executable test cases across the catalog. |
| R15 | MODERATE | Limitations incomplete: single-auditor execution risk; recovery-join analysis is structural, not temporal; shared-resource attribution ambiguity persists even with time-scoping. | All three added to Limitations, with the mitigation (scripted re-runnable queries cross-checked against the specification's independent snapshot) and the design point (the OCEL stores unit-scoped events once, at true granularity, precisely because attribution is inherently ambiguous). |
| R16 | MINOR | Duplication factor 1.000 for direct flattening presented without noting it is a projector-imposed lower bound (OCEL 2.0 permits multiple same-type relations per event). | Lower-bound status stated in Methods and Table 4 caption. |
